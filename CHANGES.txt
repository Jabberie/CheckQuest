# Changelog

All notable changes to CheckQuest will be documented here.

## 12.002

### Added
- Current multi-client support for WoW Retail 12.1.0, Classic Era 1.15.9, Burning Crusade Classic Anniversary 2.5.6, and Mists of Pandaria Classic 5.5.4.

### Changed
- Updated the TOC to advertise all supported client interface versions from one addon package.
- GitHub release packages now include CHANGES.txt alongside the addon, TOC, and license.

## 12.001

### Added
- Support for World of Warcraft 12.1.
- Added support for checking up to 50 unique quest IDs in a single command.
- Added `/cq help` and `/cq version` commands.
- Added support for extracting quest IDs from pasted text and Wowhead URLs.
- Added GitHub Actions release packaging.
- Added an MIT license.

### Changed
- Improved quest result formatting and chat output.
- Duplicate quest IDs are ignored when checking multiple quests.
- The addon version is read from the TOC metadata.
- Updated addon metadata and documentation.
- Adopted expansion-based release numbering.

### Maintained
- `/cq <questID>` and `/checkquest <questID>` functionality.
- `/rl` shortcut for Reload UI.
- `/fs` shortcut for the Frame Stack tool.

## v010 - 2022-12-17

### Changed
- Updated for World of Warcraft 10.0.2.
