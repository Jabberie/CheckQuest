CheckQuest Changelog
====================

1.2.0 - 2026-08-14
------------------
- Updated for World of Warcraft 12.1 / Interface 120100.
- Added support for checking multiple quest IDs in one command.
- Added quest ID extraction from pasted text and URLs.
- Added /cq help and /cq version commands.
- Improved chat output and status colours.
- Improved handling of uncached quest data.
- Added addon author and refreshed metadata.
- Rewrote the README with current usage and command documentation.

1.1.0
-----
- Modernized quest completion checking using C_QuestLog APIs.
- Added asynchronous quest-data loading when quest names are not cached.
- Added /cq shorthand.
- Updated convenience commands for current Retail APIs.

Legacy
------
- Original project history includes the 10.0.2 update released in December 2022.
